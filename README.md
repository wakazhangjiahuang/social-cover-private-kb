# social-cover-private-kb｜v1.8.0 candidate

本仓库当前 GitHub 可见性为 public；原定位文件记录了用户对公开仓库的批准。仓库名称中的 private 不代表 GitHub 实际权限为 private。

## 保留资产
- 64 张封面构图样本及对应缩略图
- 18 款视觉风格、17 类信息结构、8 种几何家族
- 18 个决策组件 / 179 个字段
- 225 条标题候选、225 条钩子候选及原始来源

## v1.8.0 候选改动
- 新增450条标题/钩子旁挂元数据，保留原始记录和稳定ID；当前全部待审核，不进入默认自动推荐。
- 新增任务输入、参考图、平台证据、标题声明、编辑评分和真实文件验收合同。
- 默认检索只允许已审核并显式启用的标题/钩子记录；显式查看未审核模板需传入 --include-unreviewed。
- 新增任务路由、标题门禁/评分聚合和图片文件精确验收工具。
- 不新增自动发布、实时采集平台或未经验证的效果预测。

## 验证边界
- 24条标题样本为合成合同测试，不是市场样本或效果数据。
- 评分规则为试行版，尚未独立校准。
- 平台规则可读范围、实际发布器裁切、真实CTR和受控A/B仍需独立证据。
