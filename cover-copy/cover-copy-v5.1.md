# 封面主标题与副标题创作规则 V5.1｜独立文案能力执行标准

**依据：**《三平台自媒体封面主标题与副标题创作指导书_V5.1_迭代版.docx》（2026-11-24）。
**范围：**只负责封面图片主标题、副标题及本轮授权的独立标签/CTA；不负责发布标题、笔记正文、口播、Calling、评论钩子、分镜或平台运营方案。

## 1. 版本定位与优先级

V5.1 以原封面指导书 V5.0 为主体，吸收口播稿多轮迭代中已暴露的质量问题。它是封面文案的当前执行标准，不重建视觉设计 Skill。
保留：四级质量定义、四类内容模式、九种注意力入口、理解—决策—生成—验证、七项中间产物、七道质量门禁、15组历史样例、三平台展示检查及12/18字符工作室约束。
V4、V5、V6 及旧候选库仅作历史/结构参考，不得覆盖 V5.1。历史正向样例、用户锁定文案和负向回归样例必须分开管理。

## 2. 质量定义

- **合格：**事实准确；对象可识别；主副不矛盾；内容能兑现；缩略图可读；锁定文字未被擅改。
- **对：**从目标用户共同任务出发，表达其在意的收益、判断、资料、方法或代入。
- **好：**具体、鲜明、自然；主副互补；留下明确且有答案的信息缺口。
- **验证有效：**真实目标用户理解并愿意看，且可比发布条件下的真实数据提供支持。

漂亮排版、夸张语气、感叹号、模型高分和内部认可不能替代上述判断。“对”不等于每条都写赚钱；“好”也不等于更刺激。

## 3. 从口播稿迭代中迁移的质量规律

只迁移与封面有关的方法，不复制完整口播规则：
1. 受众身份不等于受众任务；必须回答“这与用户当前什么事有关”。
2. 钩子必须有真实由头、对象、范围和材料支撑；情绪词不是事实。
3. 封面承诺必须映射到开场、正文、作品、产品、画面或证据位置。
4. 封面与已有口播/正文要讲同一件事；只核对兑现，不在本 Skill 中重写口播。
5. 吸引来的用户必须与内容真正服务的目标用户匹配。
6. 模型自评、第二模型复核和程序检查不能代替真人理解与实际验证。
7. 已知失败稿必须作为 NEGATIVE_REGRESSION 回归样例，不得混入正向示例库。

## 4. 一手材料与证据标签

优先从原始作品、产品、客户需求、订单/合同/交付、原始报告、调查原页、平台后台和实际运行记录起步。
证据分类：
- `ORIGINAL_VERIFIED`：已查看原件并能定位到页面、字段、截图、时间码或文件。
- `USER_REPORTED`：用户陈述，当前没有独立原始凭证。
- `SECONDARY_SUMMARY`：AI摘要、二手文章、会议摘要或转写，只用于线索。
- `SIMULATED`：模拟/虚构/概念示意，必须标注，不得冒充真实项目或运行。
- `STRUCTURAL_REFERENCE_ONLY`：只借表达结构，不迁移事实、金额、身份、关系或授权。
- `LOCKED_COPY`：用户明确锁定的文字，逐字保留。
- `NEGATIVE_REGRESSION`：已知失败或被否决的表达，用于防止错误复发。

交易金额、客户关系、身份、上市、预约、排名、调查、联名、工艺、实测、效率提升等强主张逐项核验。证据不足时删去、缩小、标待核或 BLOCKED；不得先写刺激标题再补事实。

## 5. 输入契约与 Topic Gate

从附件和上下文提取，不要求用户重复填写；缺失事实不得自动补造。至少识别：
- 任务模式：新创作 / 重大重写 / 简单优化 / 审核 / 锁定检查 / 复盘。
- 平台与实际展示位置：推荐列表、搜索、主页、分享预览或完整封面。
- 原始素材、现有内容/正文、用户共同任务、内容目标、锁定文字、授权和交付范围。
- 已核实事实、用户陈述、推断、模拟和未知；每项证据的来源位置。
- 现有内容能兑现的观看回报及其位置。

正式生成前，Topic Gate 五问必须有答案：
1. 这条内容服务谁的一个共同任务？不能只写职业身份。
2. 用户此刻缺少什么信息、判断、选择或经验？
3. 看完能得到什么具体回报？
4. 当前材料/正文能否真正提供该回报，证据在哪里？
5. 为什么值得现在看？没有时效依据就不制造热点。

无法说清共同任务、观看回报或材料支持时，先补内容或缩小承诺，不进入标题润色。

## 6. 共同任务与观看回报

一篇封面可以服务多个岗位，但必须围绕一个共同任务；若任务、利益或决策不同，拆成不同封面。
内部依次转换：作者事实 → 共同任务 → 用户缺口 → 观看回报 → 点击理由。
观看回报可以是商业结果、专业判断、资料/图鉴、审美与方法、人物经验；必须具体且正文可交付。不得用“提升审美、商业机会、内容价值、干货、共创”等抽象词代替实际回报。

## 7. 内容模式与九种注意力入口

先判断正文实际具备的组织方式，再选择入口。四类核心模式：真实商业案例、AI工作流教程、设计决策分析、商业机会分析；趋势/调查、图鉴/选集、风格/工艺研究、人物/合作故事按实际材料组织。
九种入口：真实结果、开发路径、时机/趋势、选择/对照、图鉴/选集、调查/参与、人物/业务转折、专业转译、具名风格/可见方法。
新创作或重大重写，内部至少比较三种实质不同的入口；每种都回答受众任务、点击理由、观看回报、证据、正文兑现和风险。不得把同一入口改三个近义句。默认只交付 AI 选定的一组主副标题，不把内部候选池交给用户挑选。
简单润色、错字修复和锁定文案检查不强制重跑入口竞争。允许否定用户原先提出的入口。

## 8. 主标题、副标题与主画面的表达契约

- **主标题：**建立第一眼识别或兴趣焦点，可写结果、问题、人物、具名风格、产品任务、图鉴对象或动作；不强制写利益句。
- **副标题：**补主标题留下的主要理解缺口，可补对象、产品、场景、方法、范围、来源、证据、情绪或观看回报；不是固定“证据栏”。
- **主画面：**提供可见对象、结果、作品、产品、过程或风格信息；文字不包办全部信息。
三者必须服务同一主要用户任务。读完两行应能回答“这是什么、为什么值得看、还想知道什么”。副标题若无新增理解/期待可省略；不得同义重复或引入第二主题。
用户锁定的主副标题、品牌名、金额、英文名、分隔符和标点逐字保留。风险另列，不得静默缩写或替换。

## 9. 封面承诺兑现

逐项拆出封面承诺，映射到已有开场、正文、作品、产品、真实画面或材料位置。若有口播，只核对封面—0至3秒—3至8秒—正文是否延续同一点击理由并增加信息；不在本规则中代写口播。
没有兑现位置时，缩小承诺、补内容或 BLOCKED。重点核验金额/收入/订单/客户/商单/上市/预约/定稿/客户选中/合作/联盟/品牌背书/第一/最热/TOP/调查居首/趋势/采购机会/实测/效率提升等词。

## 10. 三平台适配边界

- **小红书：**检查发现/搜索/列表/主页缩略图；主题对象和资料价值要清楚，不堆关键词或承诺自然排名。
- **抖音：**检查实际封面和主页作品列表；区分静态封面与自动播放首帧/开场，不把播放量当封面点击。
- **微信视频号：**检查列表、主页和分享/转发预览；脱离作者上下文仍能理解对象与价值。
同一共同任务、点击理由和展示条件下，允许三平台共用一组标题；只有展示裁切、受众熟悉度或上下文实质不同才平台化调整。不得固化“小红书=关键词、抖音=冲突、视频号=专业”。

## 11. 字符与排版预算

- **主标题默认最多12个可见字符/字素簇。**
- **副标题默认最多18个可见字符/字素簇。**
- 汉字、英文字母、数字、空格、标点、分隔符和 Emoji 均计入；复杂 Emoji 按完整字素簇计数；换行不计。
- 主标题允许1–3行，副标题允许1–2行。字符数不等于实际字宽，必须在目标字体和手机缩略图检查。
- 地点/品牌/系列标签、邀约牌和 CTA 是独立字段，不并入主副字符预算；CTA 必须获授权。
- 超限先删无作用词，不删唯一对象、产品或关键关系。用户锁定的超限文案原样保留，登记 `LOCKED_COPY`、例外理由和视觉检查；不得把历史例外推广成新创作默认。

V4/V5.0 的四组超限历史样例：DY-AC03（主13/副22）、DY-AC09（主20/副16）、WX-AC05（主13/副16）、WX-AC07（主13/副15）。四组保留为锁定历史样例，不改变新创作12/18标准。四张温泉用户认可透明文字叠加参考同样保留为用户认可的锁定参考，不构成新标题长度标准，也不是效果证明。

## 12. 七道质量门禁 G1–G7

- **G1 事实/授权：**事实、关系、数字、权属和CTA有依据。
- **G2 用户任务：**共同任务、当前缺口和观看回报清楚。
- **G3 入口：**新创作/重大重写已比较不同入口，所选入口有材料支持。
- **G4 主副组合：**主标题有焦点、副标题补缺口、两行同一主题。
- **G5 内容兑现：**每项封面承诺可定位到开场、正文、画面或证据。
- **G6 画面/平台：**完整封面主画面、文字层级、缩略图及对应平台展示检查通过；纯文案任务记 NOT_RUN，透明叠字在合成前记 NOT_APPLICABLE。
- **G7 独立验证：**事实复核、目标用户盲读、实机预览和发布数据分开记录；未执行不自动通过。

任一关键门禁 FAIL 不得发布；UNKNOWN/NOT_RUN/BLOCKED 必须保留状态和原因。总分不得抵消门禁失败。

## 13. 状态与独立验证

- `BLOCKED`：事实、授权、语义、兑现或可读性存在硬伤。
- `EDITORIAL_READY`：内部编辑门禁通过，不代表盲读或效果验证。
- `BLIND_TEST_PENDING`：尚未完成目标用户盲读/真实封面预览。
- `TESTED_CANDIDATE`：事实复核通过，目标用户盲读达到内部筛选线。
- `PERFORMANCE_SUPPORTED`：真实发布数据在说明样本、平台、时间、对照和局限后提供支持。

盲读建议5名真实目标用户，展示真实封面缩略图3秒后隐藏，不提示答案。至少4/5正确理解主题、至少3/5说出与正文一致的具体价值；小样本只作内部筛选，不是统计显著性。
发布复盘使用平台后台原始字段；没有曝光和点击分母不计算 CTR；自动播放场景的播放量不是封面点击。自然流量比较不称严格 A/B。

## 14. 评分与负样例回归

评分仅用于定位短板，不用于候选排名或发布放行。任何分数不能抵消 G1–G7 失败。模型自评不能充当独立验证。
负样例必须记录错误表现、成因、违反规则和返工位置；与正向编辑样例、用户锁定样例、结构参考分库。每次版本迭代重跑旧失败样例，确认错误不再通过。

## 15. 标准执行顺序与交付

任务路由/锁定 → 事实卡 → 用户任务卡 → 内容模式与 Topic Gate →（新创作/重大重写）三入口竞争 → 主副/画面表达契约 → 兑现映射 → 字符与缩略图检查 → 独立审查/盲读/发布回流。
七项中间结果：事实卡、用户任务卡、内容模式卡、入口竞争卡、主副标题卡、兑现映射卡、验证记录。
返工顺序：事实证据 → 共同任务 → 内容模式 → 入口 → 主副关系 → 措辞 → 版式 → 验证。不得在错误入口上反复润色。
默认只交付一组主副标题及字符数、简短点击理由、事实/兑现状态和未完成验证状态；用户未要求时不生成发布标题、正文、话题或口播。

## 16. 历史样例边界

15组历史样例按 XHS-AC01/02/04/05/07/09、DY-AC01/03/04/08/09、WX-AC02/05/07/08 保留。它们用于学习成立机制、失效条件和事实风险，不自动代表事实已核验或营销效果已验证。
插画18篇笔记对照仅用于检查封面承诺是否由原正文/画面兑现；用户只要求封面时，不改写原口播、Calling或发布文案。
四张温泉正向样例是用户认可的历史参考；原图为透明文字叠加素材，不是完整实景封面，也不是CTR或爆款证明。

## 17. 版本与系统边界

V5.1 是封面文案当前标准。V6及更早版本降为历史参考，不得在运行时覆盖V5.1。只升级文案模块的规则、字段、程序、门禁和回归测试；保留原有三平台设计、17类结构、18套视觉风格、64套构图、素材库、品牌隔离、图片生产与导出能力，不重建第二套视觉设计 Skill。
