# social-cover-studio V2.0｜完整升级知识说明

## 目标架构
单一 Skill、八个平台适配器、共享事实/价值/文本/视觉/QA 底层。A 抖音短视频；B 微信视频号；C 小红书；D 闲鱼商品/服务；E 淘宝/天猫商品；F 抖音商城/商品卡；G 抖音电商直播；H 淘宝直播。

## 五层营销决策
1. 平台与展示入口 surface；
2. 受众角色、认知阶段和当前任务；
3. 营销表达类型（一个主类型，最多一个辅助类型）；
4. 注意力入口（问题、反差、结果、现场、故事、数字、趋势、选择标准等）；
5. 四级文本合同与主画面证据。
营销表达类型不是注意力钩子，也不是官方算法分类。新创作/重大重写内部比较至少三种实质不同入口；简单修改和锁定检查不强制重跑。

## 四级文本
主标题建立第一眼识别/兴趣；副标题补足最大理解缺口；补充文案可为空，只放影响理解、比较、信任或购买决策的信息，每条需类型、优先级和证据引用；CTA 可为空，需平台允许、可执行且对用户有收益。主画面独立承担真实商品、作品、过程、UI、场景或结果证据。AI 示意不可冒充真实实拍/客户/后台。
A/B/C 保留 V5.1 主标题≤12、副标题≤18 可见字素簇默认预算；D–H 不继承 12/18，按真实入口、商品/服务身份、字段和可读性核验。

## 六阶段执行链
01 任务路由与原始资料理解 → 02 用户/买家任务与价值裁决 → 03 平台入口与营销表达竞争 → 04 四级文本与视觉策划 → 05 图片生产与逐图 QA → 06 交付与数据回流。

## 三道总关口
GATE 1 事实/授权/价值；GATE 2 平台入口/营销表达/文本职责；GATE 3 视觉兑现/平台规格/独立文件。文案细门禁 G1–G7；评分不得抵消硬失败。

## GitHub 知识治理
固定 Locator → 固定 Manifest → 定向依赖检索 → SHA 校验 → 证据/状态记录。不得浮动回退 main。现有有效资产、原始资料、图片、Prompt、工作簿和历史样例不得删除；旧版通过 historical_only/superseded/default_retrieval=false 逻辑归档。新资料必须更新 Manifest、Inventory、SHA256、检索索引、变更日志和回归测试。

## 交付边界
一张原稿对应一张独立图片；禁止合集/九宫格/拼图。文件检查、视觉验收、平台实机预览和发布效果验证分层记录。未执行项标 NOT_RUN/UNKNOWN，不得冒称通过。
