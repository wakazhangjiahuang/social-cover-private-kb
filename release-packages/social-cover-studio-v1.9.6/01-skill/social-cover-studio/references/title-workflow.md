# 封面主副标题执行入口｜V6

## 默认读取顺序
1. `references/cover-copy-v6.md`：当前最高优先级规则。
2. `references/cover-value-method.md`：四层表达、共同任务、点击动机、AI自动择优。
3. `references/title-review.md`：四项核心指标、硬门禁、试行评分与独立验证。
4. `references/title-case-atlas.json`：插画标题案例，按任务需要读取。
5. `references/hot-spring-positive-cases-v2.json`：温泉四张用户认可封面的文字、精确字符和视觉结构；仅温泉/文旅任务读取。
6. `references/illustration-note-alignment-v1.json`：仅插画封面任务按平台+ID核对原稿与兑现，不改写原口播。

默认只写封面图片主标题与副标题；副标题可省略。平台发布标题、笔记正文、话题、口播是独立字段，仅用户明确要求时生成。用户锁定文字逐字保留，事实问题写入备注。

## 生产顺序
事实卡 → 共同任务 → 观众当前利益/缺口 → 四层表达映射 → 选择主点击动机 → 正文/画面兑现位置 → 比较不同价值路径并由AI选定 → 主副/画面分工 → 汉字数与可见字符检查 → 完整封面缩略图检查 → 独立盲读/发布验证。

四层表达是内部分析，不是四行文案。不得强制把利益、钩子、关键词、证据全部写在主副标题中。主画面可承担部分信息；主副标题只补理解缺口。

## 字符和排版
主标题≤15个汉字，副标题≤18个可见字素簇；主标题允许1–3行，副标题允许1–2行。英文、数字、标点、空格和Emoji另计可见字素簇及实际字宽；换行不计。地点/品牌标签、邀约牌、CTA独立计数，不并入主副标题总数。锁定/已认可例外不静默改写。

## AI自动决策
内部比较2–3条不同的价值入口，不生成同义句凑数。先淘汰事实、受众、点击动机、互补或兑现失败项，再自动选一条最合适表达。默认只交付最终标题组合，不要求小白用户替AI挑选。最多两轮定向返工。

## 四项工作指导边界
“专家视角、一手材料、专业方法与落地、独立验证”只指导AI如何工作，不得写成公司简介、网页栏目、宣传正文或封面文字。

## 插画赛道专用对照
插画封面任务按需读取 `references/illustration-note-alignment-v1.json`。只核对封面承诺与原正文/画面；用户只要求封面时，不改写口播正文、Calling或发布文案。该样例不是营销效果证明。
