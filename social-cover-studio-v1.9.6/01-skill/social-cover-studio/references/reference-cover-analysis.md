# 参考封面分析与自定义风格适配

## 触发条件

用户上传 1–5 张封面参考图，或明确提出分析、学习、提取、适配某张/某组封面。若用户只要求诊断，停在分析；若要求重新设计，继续生成 Brief 和成品。

## 分析流程

### 1. 逐图读取

每张参考图独立建立记录，不先平均多张图。记录可见画布比例、主体、文字、网格、背景、色彩和装饰。

### 2. 视觉分析维度

| 维度 | 观察内容 |
|---|---|
| 画布/网格 | 比例、边距、安全区、栏宽、对齐轴线 |
| 构图 | 主体位置、大小、裁切、前中后景、遮挡关系 |
| 视觉锚点 | 第一眼看到的人/物/文字/数字/作品/界面 |
| 信息层级 | 主标题、副标题、标签、辅助说明的顺序和面积 |
| 字体 | 字族气质、字重、字宽、字距、行距、断行和字效 |
| 色彩 | 主色、辅助色、强调色、背景色、文字色及角色；HEX 仅作近似估计 |
| 图像处理 | 摄影光线、景深、抠图、材质、笔触、颗粒、边缘 |
| 装饰 | 边框、贴纸、箭头、图标、标签、线条及其功能 |
| 密度/留白 | 文字与图片占比、负空间、信息拥挤程度 |
| 品牌识别 | Logo、固定识别元素、系列化线索；记录但不默认复制 |
| 点击策略假设 | 可能的内容承诺、目标受众和点击动机；标为 INFERRED |
| 缩略图表现 | 缩小后标题、主体和锚点是否仍可识别 |

### 3. 证据标记

每条结论标注：

- `OBSERVED`：图像直接可见，例如标题在上方、人物位于右侧。
- `INFERRED`：根据视觉表现推断，例如可能希望制造信任感或强调结果。
- `UNKNOWN`：无法从图像确认，例如真实点击率、字体准确名称、品牌规范、图片是否真实拍摄。

置信度使用 high / medium / low；不得把推断包装成事实。

### 4. 多图比较

- 提取共同 DNA：重复出现的网格、标题层级、色彩角色、主体处理和品牌识别。
- 保留单图变量：不同内容场景、主体位置、信息密度或 CTA。
- 如果参考图彼此冲突，列出冲突，不求平均；只在用户选择会实质改变最终风格时问一个问题。

### 5. 生成参考封面 DNA Profile

建议字段：

```json
{
  "profile_id": "REFDNA-YYYYMMDD-001",
  "source_images": ["user-upload-1"],
  "observed": [],
  "inferred": [],
  "unknown": [],
  "layout_family_candidates": ["L03", "L09"],
  "visual_tokens": {
    "composition": "",
    "type_hierarchy": "",
    "typography": "",
    "color_roles": {},
    "image_treatment": "",
    "decoration_logic": "",
    "density": ""
  },
  "confidence": "medium",
  "adaptation_boundary": {
    "preserve": [],

}
```

### 6. 用户自定义

用户可自由说明：

- 希望保留：构图关系、标题层级、色彩气质、字体方向、手绘笔触、摄影氛围等；
- 希望改变：主题、主视觉、文案、配色、主体位置、信息密度、品牌元素等；
- 明确禁止：元素、风格、色彩、人物、装饰或误导表达；
- 应用上下文：品牌、行业、受众、内容类型、点击动机、商业目的、发布平台和比例。

用户未提供这些说明时，系统根据分析结果自动形成适配方案，不强制填写表单。

## 从分析到执行

1. 将参考图视觉 DNA 与本次内容 Brief 分开保存。
2. 先判断参考图的结构是否适合本次内容和证据；不适合时保留视觉气质但更换结构。
3. 将可迁移方法写入新 Brief：内容承诺、点击动机、商业目的、结构家族、主视觉锚点、标题层级、视觉 Token 和生产方式。
4. 生成时只使用用户授权的品牌资产和本轮内容素材。
5. 逐张核对：是否学到了方法、是否误复制了第三方独特表达、是否兑现本轮内容承诺。

## 许可与保存边界

用户上传参考图用于当前任务，不等于授权将图片永久保存到公共资产库。默认只在本轮分析和制作中使用。用户明确要求保存可复用风格时，可保存抽象化 DNA Profile；不默认保存第三方原图、肖像、Logo 或完整 Prompt。保存前确认用户有权保存该资产。

## 测试与迭代

可用一张用户提供的真实内容测试参考 DNA。测试失败时定位具体偏差（结构、字级、色彩、主体比例、笔触、装饰、真实性），每轮只修复关键偏差，不全面重写无关维度。
