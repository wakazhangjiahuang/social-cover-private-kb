# A–H 八平台适配器｜V2.0

所有平台共享事实、证据、四级文本、视觉生产和 QA 内核；适配器必须同时识别 platform_mode 与 surface。以下营销类型是工作室策略分类，不是平台官方算法分类。

## A｜抖音短视频
入口：推荐流、主动搜索、主页/分享；视频封面、自动播放首帧、开场段分开判断。
类型：推荐流发现、痛点解题、结果/案例证明、过程/现场演示、观点/认知反差、热点/趋势、搜索承接、产品/服务自然种草。
文本：主标题给主题与兴趣由头；副标题补观看回报/方法/范围；辅助信息按需；CTA 可省略。视觉优先真实产品、作品、过程、人物或关键帧。
算法边界：官方备案公开个性化推荐行为信号包括点击、时长、点赞、评论、分享、转发、不喜欢等；模型预测互动概率并进行排序、打散、干预和兴趣探索。搜索公开提到意图、相关性、时效性、权威性。无公开固定曝光或 CTR 阈值。

## B｜微信视频号
入口：好友推荐、算法推荐、分享预览、主页、直播入口；公众号与视频号严格区分。
类型：社交分享、人物/专业信任、真实案例/项目复盘、专业解释/决策、关系/生活共鸣、产品自然融入、连续系列。
文本：封面脱离作者上下文仍能说明主题；主标题建立命题/问题，副标题说明对象和观看回报；真实人物、作品、业务现场可作信任锚点。
算法边界：中央网信办公开说明视频号完善好友推荐与算法推荐双重机制；未公开两者比例、权重或固定分享阈值。

## C｜小红书
入口：推荐信息流、主动搜索、笔记首图、视频笔记封面、商品笔记；搜索与推荐分开诊断。
类型：搜索问题解决、选购/比较、真实体验/测评、教程/清单收藏、趋势/审美灵感、细分场景方案、案例过程。
文本：封面主题、标题字段、正文和图片围绕同一意图；关键词自然出现，不堆叠；图文首图与视频封面分开核验。
算法边界：平台研究涉及多阶段推荐排序、点击/停留预测及 query-note relevance、查询理解、taxonomy/keyword matching；论文指标不是全站固定权重或创作者可直接控制的排名公式。

## D｜闲鱼商品/服务
入口：商品/服务列表、关键词检索、筛选和详情；买家要先识别卖什么，再判断适不适合、能获得什么、有哪些条件需核对。
类型：需求发现、痛点解决、结果交付、定制解决、性价比/方案选择、专业信任、作品/案例证明、精准搜索承接。
文本：主标题可从需求/痛点/结果/选型切入；副标题必须明确商品/服务身份与选择价值；辅助文案可说明规格、成色、配件、范围、交付物、修改流程、兼容和条件；CTA 以站内查看/咨询为主。
规则边界：协议公开分类、关键词检索、筛选、收藏、关注及文字/图片/视频发布；不证明具体排序权重。虚拟商品/数字服务类目准入按账号后台核验，未知标 UNKNOWN。

## E｜淘宝/天猫商品视觉
入口：商品列表/搜索主图、轮播、SKU、详情首屏和详情图。
类型：商品识别、核心卖点、差异化选择、场景用途、功能/材质证明、SKU规格选购、品牌/服务信任、套装组合。
视觉：首图优先商品本体；轮播图分工展示卖点、场景、细节、对比、规格和信任；SKU图与实际颜色/型号一致。图片文字不能替代标题、属性和SKU字段。
规则边界：新版商品发布 Schema 2026-10-20 更新，通过 Schema/API 返回类目与发布字段规则；不可将单一类目/历史比例写成全平台通用。

## F｜抖音商城/商品卡
入口：商城货架、搜索商品结果、商品卡、商品详情、商品主图视频；不等同 A 短视频封面。
类型：搜索意图匹配、核心卖点、使用场景/痛点、选购比较、真实价格/活动、视频演示、套装组合、真实体验/证据。
视觉：商品本体和身份优先；主图、标题、属性、详情与链接一致；主图视频展示真实使用/操作。优惠需明确条件、时间、范围和计价基准。
算法边界：抖音电商算法公示提到用户行为与交易操作用于个性化商品推荐；商品搜索考虑 query 意图、相关性、时效性、商品质量；未公开固定商品卡排名权重。

## G｜抖音电商直播
资产：直播预告封面、直播间封面、场景背景、商品讲解/对比卡分开制作。
类型：直播预告/预约、直播间主题、新品发布、商品专场/精选、产品演示/体验、专业答疑、促销/福利、品牌主题活动。
文本：主标题明确本场主题/品类和进入理由；副标题补看点/商品范围/适用人群；时间、主播、优惠、库存和商品范围必须真实，预告与实际直播一致。
合规：直播间标题/封面/布景/道具不得误导；直播前审核展示和讲解内容；商品/服务与价格准确；AI生成的人物图像/视频按规定显著标识并持续提示。

## H｜淘宝直播
资产：直播预告/频道封面、直播间封面、店铺专场视觉、商品讲解卡；入口分开核验。
类型：店铺/品牌专场、精选商品/清单、新品/季节上新、价格/活动、主播专业推荐、产品体验/演示、品类解决方案、节点主题活动。
文本：主标题明确店铺/主题/品类；副标题补充本场看点与范围；时间、主播身份、商品、权益、价格和活动条件必须真实。
规则边界：淘宝直播协议约束直播内容和标题/封面等传播使用；天猫直播创建说明曾列出16:9与9:16素材，但不能证明所有当前淘宝直播账号/入口都采用相同比例，发布前须在当前后台核验。
