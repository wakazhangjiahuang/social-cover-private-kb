# 六阶段封面工作链 V2.0

01 任务路由与原始资料理解 → 02 用户/买家任务与价值裁决 → 03 平台入口与营销表达竞争 → 04 四级文本与视觉策划 → 05 图片生产/排版/逐图验收 → 06 交付与数据回流。

## 三道总关口
- G1 事实与用户价值：商品/内容身份清楚；能力、授权、案例、价格和结果有来源。
- G2 营销表达与文本职责：主类型匹配任务；主副互补；补充文案必要；CTA 合法可执行。
- G3 视觉、兑现与平台交付：画面真实表达承诺；缩略图可读；平台入口/规格已核；文件独立完整。

失败回退到最早失败阶段。高分不能抵消硬失败。简单局部修改只复验受影响字段。

## A/B 模式
A 提案：用户需先确认方向或资料未锁定时，输出受众任务、主表达类型、点击理由、四级文本、视觉证据、规格来源和风险。
B 成稿：用户已确认或明确授权直接执行时，实际生产、确定性排字、独立导出和逐图 QA。用户指定数量优先；内部候选数不等于交付图片数。
