# QA 合同 V2.0

| Gate | 核心检查 | 失败处理 |
|---|---|---|
| G1 事实/授权 | 每项主张有证据；权属、身份、数字、案例真实 | BLOCKED 或缩小承诺 |
| G2 用户任务 | 受众角色、根本需求、当前任务和利他价值明确 | 回阶段02 |
| G3 入口/表达 | platform_mode + surface 正确；主表达类型成立；必要时三入口竞争 | 回阶段03 |
| G4 文本职责 | 主标题聚焦、副标题补缺口、support_copy 有必要且有证据、CTA 可空 | 回阶段04 |
| G5 承诺兑现 | promise_map 指向原件/内容/交付位置 | BLOCKED 或补材料 |
| G6 视觉/平台 | 主体真实清晰、缩略图可读、实机裁切/规格、独立文件 | 回阶段04–05 |
| G7 独立验证 | 编辑审查、目标用户盲读、平台实机、发布数据分层 | 未执行标 NOT_RUN |

状态：BLOCKED、EDITORIAL_READY、BLIND_TEST_PENDING、TESTED_CANDIDATE、PERFORMANCE_SUPPORTED。评分只用于定位短板，不能抵消硬门禁。没有曝光与点击分母不计算 CTR；自动播放播放量不是封面点击。
