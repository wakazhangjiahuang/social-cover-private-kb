# 标题营销与证据工作流｜v1.8.0

## 顺序
受众与意图 → 可兑现利他价值 → 主/辅动机 → 标题/钩子候选 → 字段拆分 → 声明证据 → 编辑排序 → 锁字 → 成图核字。

## 输入
- 任务、平台模式与具体发布入口
- 目标受众、内容类型、主要点击/观看动机、商业目的
- 本轮真实素材、正文承诺和证据定位
- 用户锁定词、禁用词及品牌语气

## 字段分工
- cover_headline：封面主命题/主钩子。
- cover_subtitle：补充对象、条件、范围或证据。
- platform_title：平台发布标题；不得机械复制封面标题。
- description：补足正文承接与必要说明。
- topics：仅保留真实相关话题，不堆砌热词。

## 声明证据
数字、结果、亲历、权威、社会证明、比较、商业关系和稀缺声明逐项登记 claim、evidence_refs、材料定位及 SUPPORTED / UNSUPPORTED / UNKNOWN。
- UNSUPPORTED：阻断该候选进入正式成图。
- UNKNOWN：只阻断依赖该声明的表达；可移除该声明后继续。
- SUPPORTED：必须能定位本轮真实材料；占位引用和模板示例不算真实证据。

## 450条候选资产
- 保留原225标题、225钩子及稳定ID。
- 旁挂 catalog/title-hook-metadata.json，记录来源和审核状态。
- 当前450条均为 PENDING_REVIEW，auto_recommend=false；未逐条完成平台/入口/行业/内容类型/动机/证据前提审核前，不得进入默认推荐。
- 用户明确要求查看候选时，可标为“未审核模板/灵感”，不得称平台适配、爆款或已验证效果。

## 评分
使用 config/title-rubric.json 的八维0–4分编辑评分。每维必须附证据、理由和置信度；缺失时为 UNRATED。硬门禁先于分数。聚合分只用于同一合同下的编辑排序，不预测 CTR、流量或爆款概率。当前 rubric 为 TRIAL_NOT_CALIBRATED。

## SEO与关键词
记录核心查询、采用词、排除词、来源类型和核查日期。来源类型为用户后台、当前官方资料或语义推定。无可核实热度/搜索量/竞争数据时保持 UNKNOWN；语义推定不得包装为实时 SEO 数据。

## 停止与交付
输出标题字段、候选理由、证据映射、硬门禁、评分状态和待核项。不得将“候选评分通过”表述为“平台效果已验证”。
